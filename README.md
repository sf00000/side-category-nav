# 侧边分类导航（Side Category Nav）

一个 Chrome 扩展（Manifest V3）：把「收藏夹」从藏在菜单里的树，变成**常驻浏览器右侧的可视分类面板**。支持多级子分类、拖拽排序、缩进自定义，以及基于大模型的 **AI 自动归类**（用户自带 API Key，无后端）。

> 解决痛点：浏览器收藏夹一多就乱——即使分了文件夹，层级藏在菜单里、看不到全局、找东西靠记忆。本扩展让所有分类在右侧面板一眼可见、随手折叠、拖拽即整理。

## 功能特性

### 分类与链接管理
- 📁 **多级子分类**：树状结构，层数不限，每个分类可独立折叠/展开
- 🔗 **链接管理**：添加（标题必填）、编辑、删除，网站图标自动显示（Chrome 内置 `_favicon` API，不依赖第三方服务）
- ⭐ **三种收藏入口**：
  - 「☆ 当前页」一键收藏正在浏览的页面（自动带标题；**记住上次选择的分类**，连续收藏同类型网页一键确认）
  - 分类上「＋」手动添加（输入网址后自动从已打开标签页匹配标题）
  - 「⇩」从浏览器收藏夹导入（文件夹递归变分类树，散置链接归入「书签栏（散置链接）」；**URL 或标题已存在的链接一律跳过**，与 AI 归类结果不冲突，可放心重复导入）

### 拖拽排序
- 拖动分类标题：上 1/3 = 排到前面，**中间 = 变成它的子分类**，下 1/3 = 排到后面
- 拖动链接：拖到链接上 = 排序，拖到分类标题上 = 移入该分类
- 分类悬停操作「⤒ / ⤓」：一键移到当前层级的最前/最后（层级不变）
- 防呆：分类不能拖进自己或自己的后代

### 显示定制
- 固定缩进开关 + 每级缩进宽度滑块（0–40px，实时生效）
- 新建分类默认折叠、链接新标签页打开等偏好设置
- 浅色/深色主题自适应

### 🔍 搜索与过滤
- 工具栏下方全局搜索框，实时过滤链接标题、网址与分类名
- 命中关键字 `<mark>` 高亮，匹配的分类自动展开，无匹配时明确提示

### 💾 导出 / 恢复 JSON 备份
- 设置面板一键导出 `backup.json`（含全部分类、链接与设置）
- 恢复前弹窗显示备份内容统计并二次确认，防止误覆盖
- 解决「卸载扩展即清空 `chrome.storage.local`」的数据安全风险

### ✨ AI 自动归类（可选）
- **路线 A：用户自带 API Key**，零后端、零运营成本，Key 仅存本地浏览器
- 支持 DeepSeek / OpenAI / Claude，可自定义模型名
- 单次处理上限**可在设置中调整**（默认 250 条，范围 10–500，用于控制 Token 消耗）
- 工作流：收集分类与链接 → AI 给出「需变动」的归类建议 → **弹窗逐条人工勾选确认**（支持全选/全不选）→ 只应用选中项
- 安全兜底：AI 只提建议，绝不直接改数据；输出经本地校验，非法分类路径自动丢弃；**模型输出被截断时自动恢复完整条目**并明确提示

## 安装

1. 克隆本仓库：
   ```bash
   git clone <repo-url> side-category-nav
   ```
2. Chrome 地址栏打开 `chrome://extensions`，开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目目录
4. 点击工具栏上的扩展图标，右侧面板即弹出

## 使用

| 操作 | 入口 |
|---|---|
| 收藏当前页 | 工具栏「☆ 当前页」 |
| 新建分类 / 子分类 | 工具栏「＋ 分类」/ 分类标题上的「⧉」 |
| 拖拽排序、调整层级 | 直接拖动分类标题或链接行 |
| 从收藏夹导入 | 工具栏「⇩」 |
| AI 自动归类 | ⚙ 设置中填 API Key → 工具栏「✨」 |
| 缩进等显示设置 | 工具栏「⚙」 |

修改代码后需到 `chrome://extensions` 点扩展卡片上的 ⟳ 重新加载；分类/链接/设置等数据改动实时生效，无需重载。

## AI 配置说明

| 服务商 | 默认模型 | API 地址 |
|---|---|---|
| DeepSeek（默认） | `deepseek-chat` | `api.deepseek.com` |
| OpenAI | `gpt-4o-mini` | `api.openai.com` |
| Claude | `claude-3-5-haiku-latest` | `api.anthropic.com` |

- API Key 通过 `chrome.storage.local` 存储在本地，不会上传到任何服务器
- Token 消耗与「单次上限」设置成正比：250 条链接单次调用约 1–2 万 token，DeepSeek 成本约几分到一毛钱
- 原理简述：零样本分类（Zero-shot）——把收藏列表和候选分类拼成 Prompt，借助大模型的语义理解做匹配，再用本地代码校验输出、人工确认后应用

## 权限说明

| 权限 | 用途 |
|---|---|
| `sidePanel` | 右侧常驻面板 |
| `storage` | 分类/链接/设置的本地持久化 |
| `bookmarks` | 从浏览器收藏夹导入 |
| `favicon` | 显示网站图标 |
| `tabs` | 「☆ 当前页」读取当前标签页标题/网址；手动添加时匹配标题 |
| `host_permissions`（3 个 AI API 域名） | 扩展页直连大模型接口（MV3 跨域必需） |

## 数据存储

所有收藏数据存于 `chrome.storage.local`（Chrome 用户数据目录），**不在项目目录中**，与浏览器自带收藏夹相互独立。注意：**卸载扩展会清空数据**——请用设置面板的「⬇ 导出 backup.json」定期备份；重新加载、重启浏览器不影响。

数据模型（树状）：

```js
{
  categories: [
    {
      id, name, collapsed,
      links: [{ id, title, url }],
      children: [ /* 子分类，同结构递归 */ ]
    }
  ],
  settings: { indentEnabled, indentSize, defaultCollapsed, openInNewTab,
              aiProvider, aiKey, aiModel, aiMaxItems, lastCategoryId }
}
```

## 技术栈

- Manifest V3 + Side Panel API（Chrome 114+）
- 原生 HTML/CSS/JS，零依赖、零构建
- AI 直连：`fetch` 调用 OpenAI 兼容接口 / Anthropic Messages API

```
side-category-nav/
├── manifest.json      # 扩展清单
├── background.js      # service worker：点击图标打开侧栏
├── sidepanel.html     # 侧栏界面
├── sidepanel.css      # 样式（浅/深色自适应）
├── sidepanel.js       # 核心逻辑：树渲染、拖拽、导入、AI 整理
└── icons/             # 扩展图标
```
